# WTWR (What to Wear?)

## About the Project

WTWR is a React application that uses real-time weather data to suggest clothing based on current conditions. The app fetches weather from the OpenWeather API and displays clothing items filtered by temperature.

## Features

- Real-time weather data for your location
- Clothing suggestions based on temperature (hot/warm/cold)
- Add new clothing items via a form modal
- Preview clothing items in a modal
- Keyboard (Escape) and overlay click to close modals

## Technologies Used

- React
- Vite
- CSS
- OpenWeather API

## Running the Project

`npm run dev`
